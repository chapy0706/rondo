規約の要点:

- 規約の範囲内なら、営利・非営利を問わず無料で使える。年齢制限のある作品にも使える
- 編集・加工してよい。ただし、加工しても著作権は移らない。権利は制作者が持つ
- 著作権・提供の表示は要らない
- 禁止: 権利者でない者が、素材をコンテンツとして二次的に配布・販売すること。政治活動・宗教活動・反社会的勢力・違法行為に関わる使い方。公序良俗に反するサイトやコンテンツでの使用。素材を使った個人への誹謗中傷

このリポジトリでの扱い: 二次的な配布の禁止に当たらないよう、元データも変換した glb も、公開リポジトリに入れない。
