## 目的と期限

- rondo（スマホ向けゲームプラットフォーム）を、10/26（月）の発表会までに8割完成まで持っていく

- Claude Code は、コミットしない、rm -rf をしない、迷ったら止まって質問する
- ペースの目安は、窓あたり issue 3〜4本。週末は窓2回ぶん程度、平日は1日1セッション程度

## 既知の抜け

- 探索時間の設定が、実際に遊ぶルームに届かない可能性がある（issue-31 で結線済みか、実接続で確認する）
- サーバー上の移動範囲が、仮のステージ（中心から ±5 m）のまま。issue-29a で、選ばれた骨格の座標と移動の規則に置き換える（平屋は issue-44 でデータを足す）
- ルーム台帳が、supervisor の再起動で数え漏れする（発表規模では実害が小さいので見送り）
- Tilt Maze（rolling）の実接続は対象外。対戦モードは「準備中」の表示のみ
- Cloudflare の無通信切断への備えは issue-41 で実装済み。本番（Cloudflare 経由）での確認が残る
- 壁越しの射撃の見通しは issue-29b で有効にする（issue-27 では、ステージの座標が統一されていないため、実際のルームでは無効）
- 鬼 CPU の溶け込み度は、人間の隠れ側のペイント（issue-25）を見ず、未塗装として扱う（ストロークの平均色を使う計算は後回し）
