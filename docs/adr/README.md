# veryare 関連 ADR 一覧

rondo 本体の ADR（0001〜0019）に続く、veryare（旧称: めっちゃカメレオン風ゲーム）に関する設計判断。

| 番号 | タイトル |
| ---- | -------- |
| 0020 | 入力ポートを複数本に扱えるよう拡張する |
| 0021 | サーバーがプレイヤーを限定してメッセージを配信できるようにする |
| 0022 | 当たり判定はクライアント申告とサーバーの簡易検証で行う |
| 0023 | ゲーム名を veryare とする |
| 0024 | veryare のフェーズ制進行と待機ルーム |
| 0025 | ペイントはフェーズ終了時に一括同期する |
| 0026 | プレイヤー被り判定と禁止エリアのめり込み処理 |
| 0027 | 観戦モードの情報制限 |
| 0028 | 実装の許容基準は「ゲームバランスが壊れるか」の一点で判定する |
| 0029 | 選択画面をコンソール風の横スクロールシェルフにする |
| 0030 | veryare のルーム定員・参加導線・永続性 |
| 0031 | 迷路生成によるステージ構成とステージ選択 |
| 0032 | 固定骨格(10種)とランダム間取りによるステージ構成 |
| 0033 | 襖の開閉と答え合わせタイム |
| 0034 | 全プレイヤーを TPS 視点とし、鬼視点の観戦は周回カメラで行う（カメラのめり込みを許す決定は、ステージでは 0043 で置き換え。0043 は下書き） |
| 0035 | 性善説を前提とし、意図的な不正への対策は行わない |
| 0036 | 見逃しポイントといいね |
| 0037 | ペイントは5本の円柱へ描き、体へ投影して反映する |
| 0038 | CPU プレイヤー（隠れ CPU・鬼 CPU） |
| 0039 | 固定ステージ「平屋」と、歩ける格子による移動（提案・下書き） |
| 0040 | 素材は公開リポジトリに入れず、別のオリジンから配信する。素材がなくても動く（提案・下書き） |

| 0044 | 待機ルームを半径 3.5 m に広げ、待機中のメンバーをサーバーから同期する（0024 の広さと同期の扱いを置き換える。提案・下書き） |
| 0045 | ゲームが終わったルームは、同時ルーム数に数えない（0030 の「終了」を、ゲームの終了と定める。提案・下書き） |
| 0046 | フェーズの通知の長さは、通知を作った時点からの残りとする（契約の型は変えない。提案・下書き） |
