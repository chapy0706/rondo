# ADR 0027: 観戦モードの情報制限

- ステータス: 受理
- 日付: 2026-09-29

## 文脈

見つかった隠れ側プレイヤーは、鬼視点で観戦できる（鬼の気分で探すことを楽しめる）。ただし、観戦者がまだ隠れている仲間の位置を、音声やメッセージで伝えてしまうと、ゲームバランスが崩れる。

## 決定

観戦者には鬼のカメラ情報（視点）を配信してよい。ただし、まだ隠れている他プレイヤーの座標データは、観戦者には一切送信しない。rondo 自体はゲーム内音声・テキストメッセージ機能を持たない。プレイヤー同士の通話は個人の任意とし、システムとしては関与しない。この情報制限は、プレイヤー限定メッセージ（ADR 0021）の仕組みで実現する。

## 理由

- 鬼視点をそのまま見せることはゲームの魅力（鬼の気分を味わえる）であり、制限する理由がない
- 隠れ側の座標データさえ送らなければ、観戦者が鬼視点越しに偶然目にする以上の情報漏れは、システムとしては構造的に防げる
- ゲーム内音声・メッセージ機能を持たないことは、実装コストを増やさない選択でもある

## 検討した代替案

- 観戦者にも隠れ側の座標を一部見せる案。不正の温床になるため却下した
- ゲーム内にボイスチャットを実装する案。スコープを大きく広げる割に、外部の通話手段で代替できるため見送った

## 結果

- サーバーは観戦者に対し、鬼のカメラ情報のみを配信する
- 隠れ側の座標を含むメッセージは、観戦者向けの配信からは除外する
