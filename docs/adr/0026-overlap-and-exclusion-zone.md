# ADR 0026: プレイヤー被り判定と禁止エリアのめり込み処理

- ステータス: 受理
- 日付: 2026-09-29

## 文脈

隠れ側同士が近い場所に隠れてしまう「被り」を検出する必要がある。また、擬態のためにオブジェクトへ多少めり込むことは許容しつつ、過度な埋没は防ぎたい。3D空間での正確な体積判定は処理が重い。

## 決定

**被り判定**: 各プレイヤーに球体のコリジョンを持たせ、準備移動フェーズ終了時（全員の座標が確定した瞬間）に、サーバーが全員分の距離を総当たりで判定する。球体が重なっていたプレイヤーは、重なった相手を問わず全員失格とする。

**禁止エリア(めり込み)**: 各ステージオブジェクトについて、バウンディングボックス（外接する箱）を自動生成し、それを**80%に縮小**したものを禁止エリアとする。プレイヤーが禁止エリアに触れている間はカウントダウン(5秒)を表示し続け、離れれば解除する。5秒経過すると、その場から近い、あらかじめ用意した5〜6箇所の固定候補地点の中から最も近い地点へ強制移動する。床は寝そべるポーズの間のみ同様の許可とし、それ以外は完全に不可とする。

## 理由

- 球体の重なり判定は、体積の重なり率を測るより大幅に軽く、標準的な衝突判定で済む
- バウンディングボックスの自動生成により、素材ごとの手作業を省ける。位置は元のメッシュのまま変えないため、オブジェクト同士の位置関係のずれが生じない
- 固定候補地点への強制移動は、方向計算による押し出しに比べてバグの起きにくい実装で済む
- 5秒のカウントダウンにより、通り抜けざまに軽く触れる程度は許容され、「そこに留まり続ける」ことだけが防がれる

## 検討した代替案

- レイキャストによる体積の重なり率判定。処理が重く、床の違和感（走っただけで警告が出る）も生むため却下した
- ステージ全体を縮小してオブジェクトを外側に離す案。オブジェクト同士の位置関係が崩れ、隙間の実態と禁止エリアが食い違うため却下した
- 押し出し方向を計算して移動させる案。バグの可能性を懸念し、固定候補地点への移動に変更した

## 結果

- プレイヤーの球体コリジョンと、被り判定のためのサーバー側の距離計算を実装する
- ステージ読み込み時に、オブジェクトごとのバウンディングボックスから禁止エリアを自動生成する
- 禁止エリア用のカウントダウンと、固定候補地点(5〜6箇所)への強制移動を実装する
