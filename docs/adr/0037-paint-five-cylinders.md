# ADR 0037: ペイントは5本の円柱へ描き、体へ投影して反映する

- ステータス: 受理
- 日付: 2026-10-01
- 関連: ADR 0025（ペイントの同期）の、ペイントの保持・反映の方法を定める

## 文脈

ペイントはできる限り自由に描けるようにしたい。複雑な人体の表面へ直接描くには、モデルの UV（表面を平面に広げた図）への対応と、ポーズによる変形への対応が必要で、処理が重い。

## 決定

描き込み用の単純な面として、5本の円柱を用いる。胴（頭を含む）、左腕、右腕、左脚、右脚である。

- プレイヤーは円柱の面へ描く。体への反映は、描き込み面の内容をシェーダーで体に写すことで行い、モデルの UV は使わない
- 各円柱は、ポーズで曲げる前の基準姿勢（腕を広げた直立）での軸と範囲を持つ。面上の位置は「円柱を回る角度」と「軸方向の位置」で表す
- 体の各頂点は、スキンの重みが最も大きい部位に割り当てる。その頂点の、基準姿勢での位置から、割り当てた部位の円柱上の位置を求め、描き込み面を参照する。これにより、ポーズを変えても塗りが体に付いてくる
- 描き込み面は、5部位を領域として並べた1枚のキャンバスとする
- ペイント中は、基準姿勢でキャラクターを表示し、タップを円柱への交差判定で描き込み面の座標に変換して描く。描き終えたら、選んだポーズで表示する
- ストロークは描き込み面の座標で保持し、フェーズ終了時に一度だけ送る（ADR 0025）。色はグラデーションの全色から選べ、スポイトも使える
- 導入は段階的に行ってよい。ある部位の設定が難しい場合は、その部位を胴の円柱で代用して先に進み、後から分ける

## 理由

- 描き込み面を単純な円柱にすることで、タップから描画位置への変換が数式で済み、複雑なモデルへの判定が要らない
- UV に依存しないため、モデルを差し替えても使える
- 円柱は人の縦長の形に合い、「向き × 高さ」で前後左右と頭・胴・脚が対応する
- 腕と脚を別の円柱にすることで、腕だけ別の色を塗る、といった部位ごとの塗り分けもできる

## 検討した代替案

- モデルの UV 上に直接描く案。展開図上の操作が分かりにくく、ポーズにも弱い
- 球を描き込み面にする案。縦長の体では頭と足元が極に集まって潰れる
- 円柱1本の案。腕が胴の側面と同じ色になり、腕だけの塗り分けができない

## 結果

- 頭頂や肩の上は縞状に伸び、部位の境目（肩・股関節）に継ぎ目が出る。カモフラージュの用途では許容する
- 頂点の部位割り当てには、キャラクターモデルのスキン情報が必要なため、X Bot の glTF への変換が前提になる（人手作業）
- issue-25 に反映する
