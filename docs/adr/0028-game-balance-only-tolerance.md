# ADR 0028: 実装の許容基準は「ゲームバランスが壊れるか」の一点で判定する

- ステータス: 受理
- 日付: 2026-09-29

## 文脈

veryare は2週間という短期間で実装する。細部の粗さすべてに手を入れる余裕はない。何を直し、何を見送ってよいかの基準が、issueごとにばらつくと、実装判断のたびに迷いが生じる。

## 決定

veryare に関する各 issue の受け入れ条件は、次のいずれにも当てはまらない限り、実装を完了とみなす。

1. 鬼が隠れ側を意図せず操作したり、位置を教えてしまうこと
2. 隠れ側が鬼に危害を加えること
3. その他、通常のゲームであればチート行為とみなされるような挙動

見た目の粗さ、カメラの乱れ、当たり判定の甘さなど、上記に反しない不具合は許容する。

## 理由

- 基準を単一の原則に絞ることで、issueごとに個別の許容リストを作り直す手間を省ける
- 隠れ側は探索フェーズ中は移動できない（ADR 0024）ため、鬼側の描画やカメラの不具合があっても、隠れ側の位置がそれによって不当に動くことはなく、公平性への影響は生じない
- 限られた時間の中で核（対戦の公平性）を堅牢に保ったことを、発表の説得力として使う。制約は言い訳ではなく、選択と集中の証拠として示す

## 検討した代替案

- issueごとに「クリティカル/目を瞑ってよい」の詳細リストを都度作る案。issueが増えるたびにリストの保守が必要になり、基準が曖昧になりやすいため、単一原則に置き換えた

## 結果

- 以降の veryare 関連 issue の受け入れ条件は、本 ADR を引用する形で統一する
- 「ゲームバランスを壊すか」で判断に迷う場合は、ADR 0026（被り判定・禁止エリア）、ADR 0027（観戦の情報制限）など個別の権威の取り決めに照らして判断する
