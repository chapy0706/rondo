# ADR 0034: 全プレイヤーを TPS 視点とし、鬼視点の観戦は周回カメラで行う

- ステータス: 受理
- 日付: 2026-10-01
- 関連: ADR 0027（観戦の情報制限）の配信範囲を、本ADRに合わせて更新する

## 文脈

一人称視点は、プレイヤーの向きの変化がそのまま画面全体の回転になるため、3D 酔いを起こしやすい。veryare は IT に不慣れな来場者が多い発表会での利用を想定しており、特に、鬼の一人称映像をそのまま観戦者に見せると酔いやすい。

## 決定

**全プレイヤーの視点を TPS（三人称）とする。** 自キャラクターを画面中央に固定し、視点操作用のパッド（ADR 0020 の "look"）でキャラクターの周りを周回してカメラを動かす。

- **鬼**: 自分の TPS 視点で探索する。照準は画面中央とする
- **隠れ側（準備移動・ペイントフェーズ）**: 自分の TPS 視点
- **隠れ側（探索フェーズ）**: 自分の TPS 視点と、鬼 TPS 視点のどちらかを自分で切り替えられる
- **見つかった隠れ側**: 鬼 TPS 視点のみ（観戦）

**鬼 TPS 視点**とは、鬼キャラクターを画面中央に固定した周回カメラである。カメラを鬼の後方へ回せば、鬼が向いている正面方向が見える。カメラの向きは鬼の向きと独立しているため、鬼が急に振り向いても画面全体は回転しない。

**カメラの制約**: カメラとキャラクターの距離には上限を設ける。壁や襖へのカメラのめり込みは許容し、衝突による補正は行わない。カメラを急に寄せたり跳ねさせたりする動きは、酔いを誘発するため避ける（ADR 0035）。

## 理由

- 自キャラを中央に固定した周回カメラは、画面の回転が操作者の意図した時にだけ起こるため、酔いにくい
- 鬼 TPS 視点は、鬼の一人称映像と違い、鬼の向きの変化に画面が引きずられない。観戦に向く
- 探索フェーズ中の隠れ側は移動できない（ADR 0024）ため、待つ間に鬼の動きを見られる選択肢があると、緊張感と没入感が保たれる
- カメラの衝突補正は、急な寄せや跳ねを生み、酔いを誘発する。壁越しに見えても、隠れ側は移動できず、誰にも隠すべき秘密は生じないため、補正は不要と判断した（ADR 0035）

## 検討した代替案

- 一人称視点。酔いやすく、観戦に向かないため採用しない
- 観戦者に自由視点を与える案。ステージ全体が見えてしまい、ADR 0027 の情報制限を維持できないため採用しない

## 結果

- カメラは TPS の周回カメラで統一し、issue-29 で実装する（カメラ衝突の補正は行わない）
- 観戦者と、鬼 TPS 視点を選んだ隠れ側には、ADR 0027 の範囲で必要な情報だけを配信する
- 鬼の射撃の照準表示と撃つ操作は、issue-27 で定める
