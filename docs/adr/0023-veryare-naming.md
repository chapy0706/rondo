# ADR 0023: ゲーム名を veryare とする

- ステータス: 受理
- 日付: 2026-09-29

## 文脈

めっちゃカメレオン風ゲームは、rondo の目玉となるメインゲームに位置づけられた。以降の ADR・issue・ディレクトリ名で一貫した呼称が必要になる。

## 決定

正式名称を `veryare`（すごくアレ、をもじった名称）とする。games 配下のディレクトリは `games/veryare/`、マニフェストの id は `"veryare"` とする。

## 理由

- 他ゲーム（テトリス、czz 等）と同じ命名の作法（英字の短い id）に揃えられる
- 「めっちゃカメレオン風ゲーム」という説明的な呼称より、以降のドキュメントとコードで扱いやすい

## 検討した代替案

- 「かくれんぼ」で呼ぶ案。最初の README にあった同名の構想と混同しやすいため、区別のため新しい名称とした

## 結果

- 以降の ADR・issue は `veryare` の呼称を用いる
- games/veryare/、manifest.ts の id: "veryare" とする
