# ADR 0049: すごくアレのゲーム画面を、画面いっぱいの 1 枚にする

- ステータス: 提案（下書き）
- 日付: 2026-10-20
- 関連: ADR 0012（スマホ縦画面・タッチ操作）、ADR 0034・0043（TPS カメラ）、ADR 0036（見逃しポイントの視界）。本 ADR は、ほかのゲームの画面を変えない

## 文脈

実機（iPhone 16 Pro 級、Chrome。見える領域は約 402 x 683 pt）で、待機ルームとゲーム中の画面が、見える領域より約 340 pt 長く、スクロールしないとパッドに触れなかった。共通のゲームの入れ物（`PlayHost.tsx`）が、ロゴと名前・ゲームの部分・ルーム名と退出・「ゲーム選択へ戻る」を、余白つきで縦に積み、すごくアレの 3D の画面は、幅に合わせた 3:4 の高さで、パッド（120 px）はその下に並んでいた。3D の画面の上の約 130 pt の空白に見えた所は、3D の画面の上の部分（背景の色が地の色とほぼ同じ）だった。

## 決定

- 画面いっぱいにするかは、ゲームごとの印（`games/veryare/manifest.ts` の `VERYARE_FULLSCREEN`）で決め、`games/registry.ts` の `isFullscreenGame` で引く。契約の型（`GameManifest`）には足さない。印の無いゲームは、これまでの形のまま
- 枠（`platform/host/GameFrame.tsx` と `globals.css` の `.game-frame`）: `position: fixed; inset: 0`、高さは `100dvh`（使えない端末は `100vh`）、`overflow: hidden`、`overscroll-behavior: none`。viewport の meta に `viewport-fit=cover` を足し（拡大の禁止はしない）、枠の内側をセーフエリア（`env(safe-area-inset-*)`）だけ空ける。長押しの選択・二度タップの拡大・文字の選択を止める（`user-select: none`、`-webkit-touch-callout: none`、`touch-action: manipulation`。パッドは `touch-action: none`）
- 形: 上部バー（約 44 px。小さなロゴと名前、ルーム名、「⋯」メニューに、退出（確認つき）とゲーム選択へ戻る）、状態の行（フェーズ・残り時間・探索の時間と、ひとこと。最大約 64 px）、残りの高さは、すべて 3D の画面。パッドとボタンは、3D の画面の上に半透明で重ねる
- 画面ごとの部品: ポーズ・観戦・視点の切り替え・待つ間の色は左上、設定は右上、移動パッドは左下、視点パッドは右下、襖を開けると撃つは下の中央。ペイントの板と答え合わせの切り替えは、左下のシート（閉じられる。視点パッドの左、高さは 3D の画面の半分まで。中だけスクロール）。結果画面は、枠の中に一覧を置き、一覧の中だけスクロールし（`overscroll-behavior: contain`）、退出のボタンは一覧の下に固定する
- 大きさ: パッドと撃つボタンは、3D の画面の大きさで決める（`games/veryare/viewLayout.ts` の `controlSizes`。パッドは 84〜120 px、撃つボタンは 60〜80 px）
- カメラ: 3D の画面が 3:4 より縦に長くなるので、縦の画角を広げ、横の画角を 3:4 のときと同じに保つ（`fovForAspect`。上限 80°。横に広い画面では 60° のまま）。描画の解像度の上限（devicePixelRatio 2）は、これまでどおり
- 鬼の視界（見逃しポイント / ADR 0036）は、画面の形に関わらず、これまでの 3:4・縦 60° の枠で判定する（`SIGHT_ASPECT`）。端末の画面の形で、点数を変えない
- 横向きのタッチの端末では、上の端に細い案内の帯（「縦向きで遊んでください」）を出す。「×」で閉じられ、横向きで遊ぶことは止めない

## 影響

- 安全性: 勝敗・判定・契約の型は変えない。見逃しポイントの視界の判定は、これまでと同じ枠
- 変更容易性: 画面いっぱいにするゲームを増やすときは、そのゲームの manifest.ts に印を足し、registry の表に足す
- 性能: 3D の画面が大きくなるので、描く画素が増える（devicePixelRatio の上限 2 は変えない）
- 運用: 収まりは `e2e/tests/layout-fit.e2e.ts`（WebKit。iPhone の縦画面の大きさ 5 つ）で確かめる。ロビーと選択画面は、これまでどおりスクロールしてよい
