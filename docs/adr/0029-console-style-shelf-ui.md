# ADR 0029: 選択画面をコンソール風の横スクロールシェルフにする

- ステータス: 受理
- 日付: 2026-09-29

## 文脈

発表会で最初に見せる画面は TOP 画面と選択画面であり、その第一印象が発表全体の評価に直結する。現状の選択画面（issue-06）は、マニフェストを並べるだけの素朴な一覧表示にとどまっている。

ゲーム機のホーム画面（横一列のアイコンを選ぶカルーセル、選択中を拡大・強調する動き、アイコンと最小限の情報だけを見せる画面構成）は、快適に選べる UI として広く使われている構造であり、特定の製品の専有物ではない。一方で、配色・アイコンの質感・フォント・ロゴ的装飾まで特定の製品に似せることは、模倣の印象を強め、発表・ポートフォリオとして見せる上で望ましくない。

## 決定

選択画面を、横スクロールのカルーセル（シェルフ）として作り直す。選択中のカードを拡大・強調する動きを付け、画面に常時表示するのはゲームアイコンと設定アイコン程度に絞り、それ以外の装飾は削る。配色・アイコンの質感・フォントは rondo 独自のものとし、特定の製品の配色やロゴ的要素には寄せない。

画面の向きはポートレート（縦持ち）のまま、横スクロールのシェルフを縦持ち画面の中に置く。ランドスケープ（横持ち）への転換は行わない。

## 理由

- 横スクロールで選ぶという構造自体は、特定の製品に由来しない一般的な UI パターンであり、採用に問題はない
- 配色・アイコンの質感・フォントまで特定の製品に寄せると、模倣の印象が強まる。発表会・ポートフォリオとして公に見せるものである以上、rondo 独自の視覚的アイデンティティを保つ
- 縦持ちのまま横スクロールのシェルフを置く形は、Apple Arcade や Google Play Games のアプリ選択画面などで実例があり、片手操作とも相性がよい
- ランドスケープに転換すると、ADR 0012（スマホ縦画面・タッチ操作を基本とする）を覆すことになり、既存の各ゲーム（Tilt Maze・テトリス・czz・veryare）の画面回転対応まで影響が及ぶ。残り時間を考えると、この巻き込みは避けたい

## 検討した代替案

- ランドスケープ（横持ち）への転換。実機での体験としては本物のコンソールに近づくが、ADR 0012 を覆し、既存ゲームの回転対応という大きな影響範囲を生むため見送った
- 配色・アイコン・フォントまで特定の製品に近づける案。模倣の印象を避けるため採用しない

## 結果

- apps/web/src/platform/select/ を、横スクロールのカルーセルとして作り直す（issue-06 の後継として扱う）
- 画面に常時表示する要素はゲームアイコン（カード）と設定アイコンに絞り、他の装飾は削る
- 配色・アイコンの質感・フォントは rondo 独自に定める
- TOP 画面（issue-05）も、この視覚的方向性に合わせて調整する
