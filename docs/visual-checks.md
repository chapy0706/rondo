# 目視でしか確かめられない項目の一覧（issue-52）

自動の E2E（`docs/e2e.md`）で確かめられない項目を、見る画面・見るべき点・頻度で整理する。各項目の細かい手順と見え方は、`docs/e2e.md` の該当する節にある（右の列）。

## 自動で確かめていること（目視しなくてよいこと）

- 入口・同期・切断と復帰・ハートビート・接続の失敗（`make e2e`。拡張の E2E では、縦画面のスマホと WebKit でも流す）
- 素材の失敗4種（404、壊れた glb、応答しない、manifest の欠落）で、仮の表示のまま止まらないこと、正常な素材に差し替わること（拡張の E2E）
- 3D の状態の数値（フェーズ、自分の位置、視点の向き、開いている襖の数、見えている隠れ側の数、体が素材か。テスト用の口）
- 2本の指で移動パッドと視点パッドを同時に倒すと、歩きながら視点が回ること（Chromium の端末設定だけ）
- 3D ではない画面（選択画面、ロビー、つながらないときの失敗の表示、結果画面）の見た目の差分（スクリーンショットの比較。画素の 1% まで）
- 平屋のカメラが、実物のメッシュに入らないこと（`@hiraya`。素材が要る）

## 頻度の決め方

| 頻度 | いつ |
| --- | --- |
| 毎回 | 発表会の前のリハーサル（本番の配信・実機） |
| 3D を変えたとき | カメラ・体・ステージ・シェーダー・光を変える PR のたび |
| 素材を変えたとき | 平屋・キャラクター・動き・材質の glb を差し替えたとき |

## 実機

- 発表会と同じ端末（iPhone の Safari、Android の Chrome）で、本番の URL を開く
- 待機ルームで、左手で移動パッド、右手で視点パッドを同時に倒し、歩きながら視点が回ることを見る
- 片方の指を離しても、もう片方のパッドが効き続ける。指を離すと止まる
- ペイント画面で、体をなぞって塗れる。2本の指で拡大・スクロールしない

## 観戦の画面（issue-67。実機の iPhone）

運営の画面（`/lobby/veryare?operator=1`）で観戦ルームを作り（隠れ CPU 4 体、探索 100 秒）、別の iPhone（Safari、縦画面）でロビーの「観戦」の行から入る。旗が下りている間は、iPhone でも `?operator=1` を付けて開く（来場者の画面では押せない）。サーバーは、`RONDO_SPECTATE_DEV=1` で起動しておく（手元なら `RONDO_SPECTATE_DEV=1 make dev-all` のように、本番なら `docs/runbook.md`）。

| 見ること | 見るべき点 |
| --- | --- |
| 体のタップ | 3D の画面の体を軽くタップすると、追う相手が替わり、下の選択の押された印も替わる。ドラッグ（指を 12 px 以上動かす）では替わらない |
| 追従カメラ | 選んだ相手の後ろへ、なめらかに回り込む（急に回らない）。壁際・部屋の隅でも、カメラが壁の向こうに出ない（ADR 0043）。準備移動の間に鬼を選ぶと、鬼が出てくるまでは、ステージにいる最初の人を映す |
| 色 | 隠れ CPU の体が、全面 1 色で塗られている（準備移動の始めから）。鬼は鬼の体（赤） |
| 歩く動き | 準備移動の間、隠れ CPU が玄関から隠れ場所へ歩く。歩く動きで、足が床を滑らない。止まった人は待機の動き |
| 隠れ場所のポーズ | 着いて止まってから（約 0.3 秒）、隠れ場所のポーズ（立つ・かがむ・寝る）へ移る。ペイント・探索の間は、そのまま |
| ラベル | 体の上に「鬼」「隠れ 1」…が出て、下の選択と同じ |
| 次の試合 | 結果のあと「次の試合まで あと ○ 秒」が数え下がり、次の試合が始まっても、選んだ相手を追い続ける（前の隠れ場所から玄関へ滑らない） |
| 重さ | 5 分ほど見続けて、コマ落ち・発熱・電池の減りが、対戦の画面と同じくらい |
