# 目視でしか確かめられない項目の一覧（issue-52）

自動の E2E（`docs/e2e.md`）で確かめられない項目を、見る画面・見るべき点・頻度で整理する。各項目の細かい手順と見え方は、`docs/e2e.md` の該当する節にある（右の列）。

## 自動で確かめていること（目視しなくてよいこと）

- 入口・同期・切断と復帰・ハートビート・接続の失敗（`make e2e`。拡張の E2E では、縦画面のスマホと WebKit でも流す）
- 素材の失敗4種（404、壊れた glb、応答しない、manifest の欠落）で、仮の表示のまま止まらないこと、正常な素材に差し替わること（拡張の E2E）
- 3D の状態の数値（フェーズ、自分の位置、視点の向き、開いている襖の数、見えている隠れ側の数、体が素材か。テスト用の口）
- 2本の指で移動パッドと視点パッドを同時に倒すと、歩きながら視点が回ること（Chromium の端末設定だけ）
- 3D ではない画面（選択画面、ロビー、つながらないときの失敗の表示、結果画面）の見た目の差分（スクリーンショットの比較。画素の 1% まで）
- 平屋のカメラが、実物のメッシュに入らないこと（`@hiraya`。素材が要る）

## 頻度の決め方

| 頻度 | いつ |
| --- | --- |
| 毎回 | 発表会の前のリハーサル（本番の配信・実機） |
| 3D を変えたとき | カメラ・体・ステージ・シェーダー・光を変える PR のたび |
| 素材を変えたとき | 平屋・キャラクター・動き・材質の glb を差し替えたとき |

## 実機

- 発表会と同じ端末（iPhone の Safari、Android の Chrome）で、本番の URL を開く
- 待機ルームで、左手で移動パッド、右手で視点パッドを同時に倒し、歩きながら視点が回ることを見る
- 片方の指を離しても、もう片方のパッドが効き続ける。指を離すと止まる
- ペイント画面で、体をなぞって塗れる。2本の指で拡大・スクロールしない
