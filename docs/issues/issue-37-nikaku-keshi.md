# issue-37: 二角消去（1人プレイ、表示名は link）

## 背景

issue-16〜18（2048・Snake・Minesweeper）は切り捨てたが、同じ位置づけの暇つぶし用ゲームとして、二角消去とチェス（issue-38）に置き換える。

二角消去は、同じ牌を2枚選び、2回以内の折れ線（直線を含む）で結べるときに消していき、全て消せばクリアとなるゲームである。サーバーを使わず、ブラウザの中だけで完結する1人用ゲームとして、テトリスと同程度の規模で作る。

優先度は低い。気が向いたときに、短い時間で作れる形にする。切る順の最初に置く。

## スコープ

### このissueでやること

- 盤面と牌
  - 盤面は小さく固定する（例: 8列×6行、12種類×4枚で48枚）。実装時に大きさを調整してよい
  - 牌の見た目は、画像素材を使わず、文字や記号を使った麻雀牌風の表示とする
- 消去ルール
  - 同じ種類の牌を2枚選び、折れ線が2回以内で結べるときに消す
  - 経路は、他の牌の上を通れない。盤面の外周の外側は通ってよい
  - 選択は、1枚目をタップ、2枚目をタップで行う。結べないときは選択を解除する
- 初期配置
  - 牌をペアで置いてから混ぜる
  - 開始時に、消せるペアが最低1組あることを保証する
- 詰み判定とシャッフル
  - 消せるペアが残っていない状態を、詰みとして判定する
  - 詰みのときに、残っている牌をシャッフルするボタンを出す
  - シャッフル後に、消せるペアが最低1組あることを保証する（なければやり直す）
- お助けボタン
  - 1回目から3回目は、今消せるペアを1組示す（2枚を強調表示する）
  - 4回目以降は、ボタンが「答えを見る」に変わる
  - 「答えを見る」を押すと、消せるペアを0.5秒間隔で1組ずつ自動で消していく
  - 詰んだら、自動でシャッフルして続ける。無限に続かないよう、シャッフル回数に上限を設け、上限に達したら理由を表示して止まる
  - お助けの使用回数は、結果に表示する
- クリアと結果
  - 全て消したらクリア表示とする。クリアまでの時間とシャッフル回数を表示する
  - やり直しボタンを置く
- 遊び方
  - 縦画面のスマホで遊べるタッチ操作とする

### このissueでやらないこと

- 対戦、ランキング、サーバー通信、契約の変更
- アニメーションの作り込み
- 牌の画像素材の作成
- 盤面の完全な解答可能性の保証（初期配置で1手以上の保証までとする）

## 設計方針

- 経路判定、消せるペアの有無の判定、詰み判定、シャッフルは、画面から切り離した純粋な関数にする
- 判定ロジックはテストファーストで書く
- 乱数は注入できるようにして、テストで再現できるようにする
- 既存の1人用ゲーム（テトリス）の登録の仕方、画面の枠組み、結果の扱いを踏襲する。新しい基盤は作らない
- 通っていない機能は選択画面に出さない

## 受け入れ条件

- 直線、1回折れ、2回折れで結べるペアが消え、3回以上の折れが必要なペアは消えない（テストで確認）
- 他の牌を通り抜けるペアは消えない（テストで確認）
- 初期配置とシャッフル後に、消せるペアが1組以上ある（テストで確認）
- 詰み判定が正しく、詰みのときだけシャッフルボタンが出る
- 全消しでクリア表示が出る
- お助けが3回目まではペアを示し、4回目から「答えを見る」に変わる（テストで確認）
- 「答えを見る」で0.5秒間隔の自動消去が進み、詰み時に自動でシャッフルされ、上限で止まる
- スマホの縦画面で遊べる
- `make verify` が通る
