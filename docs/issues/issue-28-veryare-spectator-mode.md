# issue-28: veryare 観戦モード

## 背景

見つかった隠れ側プレイヤーが、鬼視点で観戦できる状態を実装する（ADR 0027）。issue-27（当たり判定）で「見つかった」状態になったプレイヤーが対象。

## スコープ

### このissueでやること

- 「見つかった」状態のプレイヤーを観戦モードへ遷移させる
- 鬼の位置・向き・ポーズを、探索フェーズの間、継続して観戦者へ配信する。観戦者は、鬼を画面中央に固定した周回カメラ（鬼 TPS 視点、ADR 0034）で見る。探索フェーズ中に鬼 TPS 視点を選んだ隠れ側も、同じ配信を受ける
- 観戦者にも、探索フェーズ開始時の一括配信（issue-25）と同じ、隠れ側全員の状態を見せる。鬼の周囲の世界を制限なく見せることで、見つかった後に退屈して離脱することを防ぐ（ADR 0035）
- 観戦モードでは、ゲームへの操作参加ができないようにする

### このissueでやらないこと

- ゲーム内音声・テキストメッセージ機能（rondo は持たない。通話は個人の任意、ADR 0027）

## 設計方針

- 性善説を前提とし、観戦者への情報の制限は設けない（ADR 0035）。ゲーム内音声・テキストを持たない点（ADR 0027）は維持する
- 画面の酔いやすさを避けるため、観戦カメラは鬼の向きに引きずられず、急な寄せや跳ねがないようにする（ADR 0034）
- 受け入れの基準は ADR 0028 に従う

## 受け入れ条件

- 「見つかった」プレイヤーは、鬼の視点を見られる観戦モードになる
- 観戦モードでは、ゲームへの操作（移動・射撃）ができない
- 観戦者（および鬼 TPS 視点を選んだ隠れ側）の画面に、鬼と、鬼の周囲の隠れ側が描画される
- 鬼が動くと、観戦者のカメラ（鬼を中心に固定）が追従する
- `make verify` が通る

## 段階

1. 「見つかった」状態から観戦モードへの遷移を実装する
2. 鬼の位置・向き・ポーズを観戦者へ継続配信する仕組みを実装する
3. 観戦者の画面で、鬼 TPS 視点の周回カメラと、隠れ側の描画を実装する
4. 観戦モード中の操作を無効化する
