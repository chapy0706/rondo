# issue-28: veryare 観戦モード

## 背景

見つかった隠れ側プレイヤーが、鬼視点で観戦できる状態を実装する（ADR 0027）。issue-27（当たり判定）で「見つかった」状態になったプレイヤーが対象。

## スコープ

### このissueでやること

- 「見つかった」状態のプレイヤーを観戦モードへ遷移させる
- 観戦者に鬼のカメラ情報（視点）を配信する
- 観戦者には、まだ隠れている他プレイヤーの座標データを一切送らない
- 観戦モードでは、ゲームへの操作参加ができないようにする

### このissueでやらないこと

- ゲーム内音声・テキストメッセージ機能（rondo は持たない。通話は個人の任意、ADR 0027）

## 設計方針

- 観戦モードの情報制限は ADR 0027 に従う。プレイヤー限定メッセージ（issue-23 / ADR 0021）の仕組みで実現する
- 隠れ側の座標を含むメッセージは、観戦者向けの配信経路に含めない（クライアント側でのフィルタではなく、サーバーが送信しない）
- 受け入れの基準は ADR 0028 に従う

## 受け入れ条件

- 「見つかった」プレイヤーは、鬼の視点を見られる観戦モードになる
- 観戦モードでは、ゲームへの操作（移動・射撃）ができない
- 観戦者向けの配信に、まだ隠れている他プレイヤーの座標データが含まれないことがテストで確認できる
- `make verify` が通る

## 段階

1. 「見つかった」状態から観戦モードへの遷移を実装する
2. 鬼のカメラ情報を観戦者へ配信する仕組みを実装する
3. 観戦者向け配信から隠れ側の座標を除外する（サーバー側の配信ロジックで保証する）
4. 観戦モード中の操作を無効化する
