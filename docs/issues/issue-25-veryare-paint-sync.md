# issue-25: veryare ペイントの実装と同期

## 背景

隠れ側が擬態のためにキャラクターへ施すペイントを実装し、フェーズ終了時に一括で鬼へ同期する（ADR 0025）。issue-24 のフェーズ管理を前提とする。

## スコープ

### このissueでやること

- ペイントUI（色選択：グラデーション全色、スポイト機能）
- ストローク（座標・色の配列）としてのペイントの保持
- ペイントフェーズ中はローカル状態のみで完結させる
- フェーズ終了時、ストロークデータを一度だけサーバーへ送信する
- 探索フェーズ開始時、サーバーが鬼クライアントへストロークデータを配信し、擬態後の見た目を描画する

### このissueでやらないこと

- ペイントの逐次同期（ADR 0025 により対象外）
- 被り判定・禁止エリア（issue-26）

## 設計方針

- ペイントの同期は ADR 0025 に従う。ペイント中は他プレイヤーに一切見せない
- ストロークデータの型は packages/contracts に定義する
- 受け入れの基準は ADR 0028 に従う

## 受け入れ条件

- 隠れ側がグラデーション全色から色を選び、スポイトで既存の色を拾える
- ペイントフェーズ中、他プレイヤーには自分のペイントが見えない
- フェーズ終了時に一度だけストロークデータが送信される（逐次送信されないことをテストで確認する）
- 探索フェーズ開始後、鬼クライアントに隠れ側の擬態後の見た目が反映される
- `make verify` が通る

## 段階

1. contracts にストロークデータの型を定義する
2. ペイントUI（色選択・スポイト）を実装する
3. ローカルでのストローク保持を実装する
4. フェーズ終了時の一括送信を実装する
5. 鬼クライアントでの受信・描画反映を実装する
