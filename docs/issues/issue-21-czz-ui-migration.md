# issue-21: czz の起動画面統合（本家UI資産の一括移植）

## 背景

issue-20 で、czz が最小構成（コマンド選択UI＋採点）で遊べる状態になった。czz 本家のリポジトリには、5ヶ月かけて発表会向けに作り込んだ起動画面が既に存在し、マスコット・BGM・音声演出等はすべてこの起動画面に含まれている。

当初は CommandBuilder や周辺 UI 資産を優先度付きの候補として少しずつ移す方針だった（旧issue-21）が、それらの多くが「起動画面」という1つのまとまりとして本家に既に存在することが分かったため、候補を個別に選んで段階的に移すのではなく、起動画面ごと一括で移植する方針に変更する。

issue-19・20 で確立した核（採点エンジン、コマンド選択UI）は、既に単独で動く状態にある。その土台の上に起動画面を乗せる形になるため、段階を細かく刻む必然性は薄い。

**実装状況（追記）**: 起動画面・マスコット・BGM/効果音は実装済みで、実際に遊んでみて概ね良好と判断した。唯一の修正点として、起動画面に「初心者モード⇔通常モードの切り替えトグル」が表示されているが、発表会（IT初心者9割）を踏まえて初心者モード固定とするため、このトグルは非表示にする。UNIX表記・並べ替えと3段お題・表記切り替え・結果表示の整合（旧issue-21の候補3〜6）には着手しない方針とした。

## スコープ

### このissueでやること

- czz 本家の起動画面（ロゴ・マスコット・BGM・音声演出を含む）を rondo に統合する
- 起動画面から、issue-20 で実装した出題画面への遷移を繋ぐ
- GameManifest に `launchScreen: "custom"` を設定し、czz が基盤共通の起動画面（issue-30）を経由せず、自身の起動画面を表示するようにする
- 既存の games/czz/ 実装（採点ロジック、コマンド選択UI）は、起動画面を含めて整理し直す形で構わない（破壊的な作り直しを許容する）
- **初心者モードに固定する**: 起動画面の「初心者モード⇔通常モード」切り替えトグルを非表示にする。モードの判定・分岐ロジック自体は残してよいが、UI 上でユーザーが切り替えられないようにし、常に初心者モードの値で固定する

### このissueでやらないこと

- 採点ロジック・お題データそのものの変更（issue-19 で確立済み）
- コマンド選択UIの操作方式そのものの変更（issue-20 で確立済み）
- veryare の起動画面（サーバーを探す／作るの2択。別issue）
- UNIX表記の表示、並べ替えと3段お題、結果表示のさらなる整合（旧issue-21の候補3〜6。今回は対象外とする）

## 設計方針

- `.reference/czz/` を参照する（残っていなければ再度 clone する: `git clone <czzのURL> .reference/czz --depth 1`）
- czz は本家の時点でスマホ向けデザインとして作られているため、幅の調整はほとんど不要な想定。ADR 0012（スマホ縦画面・タッチ操作）に沿っているかは実装時に確認する
- DB・認証・fetch への依存を持ち込まない方針（ADR 0004・0019）は、起動画面の統合後も維持する。マスコット・BGM・音声は静的アセットとして持ち込み、外部通信を伴わない
- 起動画面から出題画面への遷移は、rondo の SoloGame 契約（useSoloGame、reportResult の呼び方）ときちんと繋がるようにする

## 受け入れ条件

- 選択画面から czz を選ぶと、基盤共通の起動画面ではなく、czz 本家の作り込んだ起動画面（マスコット・BGM含む）が表示される
- 起動画面に、初心者モード⇔通常モードの切り替えトグルが表示されない
- 常に初心者モードの配色・挙動（マスコット表示等）になる
- 起動画面から操作して、issue-20 の出題画面に進める
- 出題画面以降の挙動（採点、reportResult）に変化がない
- 外部への通信・DB・認証への依存が持ち込まれていない
- スマホの縦画面で起動画面が違和感なく表示される
- `make verify` が通る

## 段階

1. `.reference/czz/` の起動画面まわりのコンポーネント・アセット（マスコット・BGM・音声ファイル）を確認する
2. games/czz/ を、起動画面を含めた構成に整理し直す（既存実装の破壊的な作り直しを許容する）
3. 起動画面から出題画面への遷移を実装する
4. GameManifest に `launchScreen: "custom"` を設定する
5. 初心者モード⇔通常モードの切り替えトグルを非表示にし、常に初心者モードで固定する
6. スマホ実機（またはDevToolsの縦画面表示）で見た目を確認する

## 関連

- 先行: issue-19 / issue-20 / issue-30（GameManifest の launchScreen 拡張。本issueの `launchScreen: "custom"` はこれが定義済みであることを前提にする）
- ADR: 0004 / 0012 / 0019
- 関連: veryare の起動画面（サーバーを探す／作る）も同様の `launchScreen: "custom"` パターンを使う
